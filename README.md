# Excel Sales Analytics - AtliQ Hardwares

## 📊 Project Overview
This project contains a detailed sales and financial analysis for **AtliQ Hardwares**, a fictional hardware company. The analysis was done in Excel to understand customer performance, market performance vs target, and Profit & Loss statements.

This project is part of my Data Analytics learning journey.

## 🏢 Company: AtliQ Hardwares
AtliQ Hardwares sells computers and accessories across multiple markets and customers globally.

## 📁 Reports Included

All reports are available 

| Report Name | Description |
| :--- | :--- |
| **Customer Performance Report** | Shows sales by each customer for 2019, 2020, 2021. Includes 21 vs 20 growth %. Analysis done with conditional formatting to highlight top customers. |
| **Market Performance vs Target Report** | Compares actual sales vs target sales for each country/market (Australia, USA, India, etc.). Shows if we achieved target or not. |
| **P&L Statement by Fiscal Year** | Profit and Loss analysis by year. Shows Net Sales, COGS, Gross Margin, and Gross Margin %. |
| **P&L Statement by Markets** | Shows Net Sales, COGS, Gross Margin for each market/country to identify most profitable markets. |
| **P&L Statement by Months** | Monthly P&L trend analysis. Helps to see seasonality and monthly profit trends. |

## 🛠️ Tools Used
* **Microsoft Excel** - For data cleaning, Pivot Tables, Formulas, Conditional Formatting
* **PDF** - Exported final reports

## 🔑 Key Metrics Analyzed
* Net Sales (in INR)
* COGS (Cost of Goods Sold)
* Gross Margin & Gross Margin %
* Sales Growth - 21 vs 20 (Year over Year)
* Market Performance vs Target %

## 💡 Key Insights (from reports)
* Top customers like Amazon, AtliQ eStore, and electrical stores drive major revenue.
* Some markets over-achieved target while some are under-performing (shown in red).
* Gross Margin % improved from 2020 to 2021.
* Monthly trend shows seasonality in sales.
